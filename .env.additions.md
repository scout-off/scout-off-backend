# Environment Variables to Add to .env.example

Add these sections to `.env.example`:

```env
# ----------------------------------------
# OpenAPI Linting (Spectral)
# ----------------------------------------
# Run with: npm run lint:openapi
# Checks structural validity, operationId presence, error schemas, etc.
# Set to false to skip in CI if needed (not recommended).

# ----------------------------------------
# Cache Store
# ----------------------------------------
# CACHE_MAX_ENTRIES — Optional. Max entries in the in-memory CacheStore
# before LRU (Least Recently Used) eviction. Default: 1000. Integer >= 1.
# Note: This consolidates the previous CACHE_MAX_SIZE and PLAYER_CACHE_MAX_SIZE
# variables into a single unified in-memory cache implementation.
CACHE_MAX_ENTRIES=1000

# ----------------------------------------
# Request Timeout and Abort
# ----------------------------------------
# REQUEST_TIMEOUT_MS is already defined above.
# When set, the timeout middleware creates an AbortController and stores
# its signal in the request context. Downstream services (RPC, IPFS, DB, loops)
# can access the signal via getRequestSignal() and check isRequestCancelled()
# to bail out early if the request times out or the client disconnects.

# ----------------------------------------
# API Documentation
# ----------------------------------------
# API_DOCS_MODE — Controls visibility of the OpenAPI spec and Swagger UI.
# Accepted values: "public", "admin", "disabled"
#   public   — Docs are publicly accessible (development/test default)
#   admin    — Docs require admin role authentication (staging/production default)
#   disabled — All /api/docs/* endpoints return 404
# Default: "public" in development/test, "admin" in staging/production
API_DOCS_MODE=public

# API_DOCS_HIDE_ADMIN — Only used when API_DOCS_MODE=public.
# When true, the served OpenAPI spec hides /admin/* paths and admin-only components.
# This prevents exposing admin endpoint shapes to public audiences.
# Default: false
API_DOCS_HIDE_ADMIN=false
```

## Deprecated Variables (To Be Removed)

The following variables are now consolidated into CACHE_MAX_ENTRIES and should be removed from deployments:

```env
# DEPRECATED — replaced by CACHE_MAX_ENTRIES
# CACHE_MAX_SIZE=1000

# DEPRECATED — replaced by CACHE_MAX_ENTRIES
# PLAYER_CACHE_MAX_SIZE=1000
```

## Migration Guide

**For existing deployments:**

1. If CACHE_MAX_SIZE is set, use that value for CACHE_MAX_ENTRIES
2. If PLAYER_CACHE_MAX_SIZE is set, use that value for CACHE_MAX_ENTRIES
3. Remove the old variables from environment
4. Remove or update CI/deployment scripts that reference the old names

**For new deployments:**

Use CACHE_MAX_ENTRIES directly; the old variables are not supported.

## Example Configurations

### Development
```env
API_DOCS_MODE=public
API_DOCS_HIDE_ADMIN=false
CACHE_MAX_ENTRIES=1000
```

### Staging
```env
API_DOCS_MODE=admin
API_DOCS_HIDE_ADMIN=false
CACHE_MAX_ENTRIES=5000
```

### Production
```env
API_DOCS_MODE=admin
API_DOCS_HIDE_ADMIN=false
CACHE_MAX_ENTRIES=10000
```

### High-Security Production (Hide Admin Endpoints)
```env
API_DOCS_MODE=public
API_DOCS_HIDE_ADMIN=true
CACHE_MAX_ENTRIES=10000
```

## Helm Integration

Update your Helm `values.yaml`:

```yaml
# values.yaml
env:
  API_DOCS_MODE: admin
  API_DOCS_HIDE_ADMIN: "false"
  CACHE_MAX_ENTRIES: "10000"

# For sensitive deployments, override:
# values-production.yaml
env:
  API_DOCS_MODE: admin
  API_DOCS_HIDE_ADMIN: "true"  # Hide admin endpoints from public spec
```

## Backward Compatibility

If you have scripts or configurations that reference the old env vars:

- **CACHE_MAX_SIZE** → use **CACHE_MAX_ENTRIES**
- **PLAYER_CACHE_MAX_SIZE** → use **CACHE_MAX_ENTRIES**

The old variables will cause no errors if left in the environment (they're simply ignored), but should be removed for clarity.
